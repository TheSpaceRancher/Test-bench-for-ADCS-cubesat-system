Magnetic Test Bench for 1U CubeSats

This repository contains all of the resources for the magnetig test bench for 1U cubesats, developed by Universidad Popular Autónoma del Estado de Puebla (UPAEP)

Subsystems

This project is composed of 3 subsystems:

1. **Helmholtz coils**
2. **MADCST-Sat** (1U CubeSat ADCS model)
3. **RM3100** (payload of the MADCST-Sat)
